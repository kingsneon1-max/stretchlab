STRETCHLAB COMPLETE v3
PWA Android untuk jadwal peregangan, timer, checklist, kalender, riwayat, statistik, panduan dan pengaturan.

ISI:
- index.html: aplikasi.
- manifest.webmanifest: identitas PWA.
- sw.js: cache offline.
- icon-192.png dan icon-512.png: ikon instalasi.

PENTING TENTANG VIDEO:
Versi ini memakai ilustrasi gerak skematis SVG yang dibuat khusus dan disimpan di dalam aplikasi, sehingga dapat ditampilkan offline. Ini bukan rekaman video manusia nyata. Video YouTube umumnya streaming dan tidak otomatis tersedia offline; menyimpan video pihak lain ke dalam aplikasi membutuhkan izin/lisensi yang sesuai. Untuk video demonstrasi manusia nyata, gunakan video milik sendiri atau berlisensi dan bundel filenya secara sah.

CARA UPDATE GITHUB:
1. Ekstrak ZIP.
2. Buka repository GitHub > Add file > Upload files.
3. Unggah SEMUA file dari ZIP langsung ke root repository (sejajar dengan index.html lama).
4. Commit changes.
5. Settings > Pages harus tetap main / (root).
6. Tunggu deployment selesai.
7. Buka https://kingsneon1-max.github.io/stretchlab/ saat online dan refresh.
8. Uji offline dengan mode pesawat setelah halaman selesai dimuat satu kali.

CATATAN:
- Data jadwal dan riwayat disimpan lokal di browser/perangkat.
- Ekspor cadangan sebelum menghapus data browser atau pindah perangkat.
- Jam pagi/malam adalah jadwal panduan, bukan alarm otomatis.
- Aplikasi ini bukan pengganti saran dokter/fisioterapis.
