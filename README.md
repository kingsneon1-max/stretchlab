# StretchLab Complete V5

PWA peregangan untuk Android/browser. Berisi beranda, sesi pagi/malam, panduan gerakan, timer konfirmasi, jeda/lanjutkan, ulangi, lewati, checklist, kalender sederhana, progres, pengaturan, ekspor cadangan, dan cache offline.

## Terbitkan di GitHub Pages
1. Ekstrak ZIP.
2. Unggah semua isi folder ke root repository GitHub.
3. Buka Settings → Pages.
4. Pilih Deploy from a branch, branch `main`, folder `/(root)`, lalu Save.
5. Tunggu deployment dan buka situs melalui Chrome.
6. Buka sekali dengan internet untuk mengisi cache offline.
7. Pilih menu Chrome → Install app / Tambahkan ke layar utama.

## Catatan
- Timer dimulai hanya setelah tombol Konfirmasi & mulai ditekan.
- Browser dapat menangguhkan timer ketika aplikasi ditutup atau lama berada di latar belakang.
- Panduan saat ini memakai simbol/ilustrasi sederhana, bukan video demonstrasi nyata.
- Gerakan bersifat panduan peregangan umum. Hentikan jika muncul nyeri tajam, kesemutan, pusing, atau gejala memburuk.
